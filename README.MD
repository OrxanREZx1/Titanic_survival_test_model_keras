# Titanic Survival Prediction

This project is a data analysis and machine learning solution for predicting survival on the Titanic. It is based on the classic Titanic dataset from [Kaggle](https://www.kaggle.com/c/titanic).

## 🧠 Project Overview

The notebook `Titanic117.ipynb` performs the following:

- Loads and explores the Titanic dataset
- Cleans and preprocesses the data
- Applies machine learning models to predict survival
- Evaluates model performance
- (Optional) Optimizes models or compares multiple algorithms

## 📁 Files

- `Titanic117.ipynb`: Main notebook containing the full analysis and model training
